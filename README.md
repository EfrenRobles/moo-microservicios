Moo Microservices - High Performance Specialization

Stack: Java 25, Spring Boot 4, Monorepo Architecture.

Infraestructura: WSL2/Lima con Docker Engine nativo (No Docker Desktop required).

Guía rápida: 1. git clone ...
2. ./moo setup
3. ./moo build

Plataforma modular para microservicios basada en Spring Boot, Spring Cloud, Kubernetes y prácticas modernas de ingeniería.

Este repositorio sirve como base para construir un ecosistema completo de servicios, librerías compartidas, infraestructura y herramientas de desarrollo.
